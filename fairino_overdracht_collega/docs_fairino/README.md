# FAIRINO documentation

Local reference copy for the FAIRINO robot simulator and WebApp work.

Source: https://fairino-doc-en.readthedocs.io/latest/

Useful starting points:

- `webapp_access.html` - WebApp login and interface overview.
- `manual_teaching.html` - Manual teaching and recording teaching points.
- `points.html` - Program -> Points / teaching management.
- `graphical_programming.html` - Graphical programming, PTP, LIN, Wait, and I/O blocks.
- `coding.html` - Program coding reference.
- `frlua_programming_script_manual.pdf` - FRLua programming script manual.
- `communication_command_protocol.pdf` - Robot controller command protocol.
- `status_feedback_protocol.pdf` - Robot 8083 status feedback protocol.
- `simmachine_intro.html`, `simmachine_vmware.html`, `simmachine_docker.html` - SimMachine setup notes.

`download-manifest.json` lists every downloaded file with its source URL and file size.
